# Changelog

## 1.0.0 — 2026-08-29

- Initial release of the Universal Agent Skills Library.
- Added the `web-research` skill (v1.0.0).
- Added platform adapters for Windsurf, Devin CLI, and OpenAI.
- Added universal skill schemas (`skill.schema.json`, `skill.schema.yaml`) and frontmatter schemas.
- Added `validate.ps1` and `quality-gate.ps1` validation scripts.
- Added GitHub Actions quality gate CI workflow.
- Added skill registry (`REGISTRY.md`) and machine-readable catalog (`catalog.json`).
