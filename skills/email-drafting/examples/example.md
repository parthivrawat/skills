# Example: email-drafting

## Input

```yaml
intent: Follow up after a project kickoff meeting
recipient: Sarah Chen
key-points:
  - Thank her for attending.
  - Share the link to the shared drive.
  - Ask her to review the timeline by Friday.
tone: professional
```

## Expected Output

A Markdown email draft with recipient, subject, greeting, body covering the key points, closing, and a note that the draft is for review and has not been sent.
