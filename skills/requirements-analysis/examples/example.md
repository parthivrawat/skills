# Example: requirements-analysis

## Input

```yaml
request: |
  I need a login page where users can sign in with their email and
  password. It should also show an error if the credentials are wrong.
domain-context: consumer web application
detail-level: standard
```

## Expected Output

A Markdown requirements document with goals, functional and non-functional requirements, acceptance criteria, assumptions, open questions, conflicts, and next steps.
